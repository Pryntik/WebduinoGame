## Lancement du jeu

Pour lancer le jeu, il faut utiliser la commande suivante : `docker compose up --build`
et en parallèle lancer le programme arduino sketch.

## Documentation

Pour pouvoir utiliser un arduino avec le jeu, il faut que vous connectiez votre arduino sur le port /dev/ttyUSB0.
et reproduire le montage arduino correspondant à l'image situé dans le dossier Arduino/assets/montage.png
